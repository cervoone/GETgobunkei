# 英語のねっこ！5文型マスターアプリ

koubun150と同じ構成（HTML + CSS + 素のJavaScript、外部ライブラリなし）で作った、
5文型の練習アプリです。パスワードなし。GitHub → Vercelでそのままデプロイできます。

## ファイル構成
- `index.html` … 画面の骨組み（ホーム／設定／クイズ／解説／結果）
- `style.css` … デザイン（koubun150と同じ配色・雰囲気）
- `data.js` … 問題データ本体（**ここに問題を追加していきます**）
- `app.js` … アプリの動作ロジック

## 問題の追加方法
`data.js` の `QUIZ_DATA` 配列の末尾に、以下のどちらかの形式でオブジェクトを追加するだけです。
追加すると、ホーム画面の「◯問」表示や、各レベルの出題範囲が**自動で**更新されます
（コードを他に触る必要はありません）。

### 定義問題（「〜って何？」型）
```js
{
  id: 55,                 // 他と重複しない数字
  pattern: 3,              // 0=キホンのキ, 1〜5=第1〜5文型
  type: 'definition',
  question: '問題文',
  answer: '答え',
  explanation: '解説ページに表示される説明文'
}
```

### 4択問題
```js
{
  id: 56,
  pattern: 3,
  type: 'choice',
  question: '問題文',
  choices: ['選択肢A', '選択肢B', '選択肢C', '選択肢D'],
  correctIndex: 0,          // 正解が choices の何番目か（0始まり）
  explanation: '解説文'
}
```
選択肢の並び順はアプリを開くたびに自動でシャッフルされるので、
`choices` に書く順番は自由です（`correctIndex`さえ実際の場所と合っていればOK）。

## レベル（トップ画面のバナー）について
`data.js` の `LEVELS` で、どのpattern番号を集めるかを定義しています。
今後「第6文型」のような区分を増やしたい場合は、ここに追記すれば
ホーム画面のバナーも自動で増えます。

## 今回作った仕様のメモ
- 問題画面／解答画面の行き来：「前の問題・次の問題」（未回答の状態で表示）と
  「前の解答・次の解答」（回答済みの状態のまま表示）の2種類のペアがあります。
- 「解説を見る」で開く解説ページには、それ専用の「前の解説・次の解説」があり、
  クイズの進行状況やスコアに影響を与えずに解説だけを見比べられます。
- 前の問題に戻ってもう一度答え直すと、正誤の記録はきちんと上書きされるので、
  二重にカウントされる心配はありません。
